MATHEMATICAL FOUNDATIONS & THE 28px PARADOX

1. Deterministic Z-Plane Law: In BEHTML, arbitrary CSS z-index values (e.g. 99, 999, 9999) are strictly prohibited. Every stacking level is an integer multiple of 32: z-index = Layer * 32. This guarantees non-colliding layers across all plugins and components.

2. The 28px Paradox (Generalized Container Padding Law): Vertical padding is applied once per container footprint, not once per quantized row: visual_height = (y_span * 32px) - 4px (with 2px top padding and 2px bottom padding). For y_span = 1, visual height is exactly 28px (+ 4px pad = 32px). For y_span = 2, visual height is 60px (+ 4px pad = 64px).

3. Production Occlusion vs. Inspection Mode: In production runtime, layers stack natively via CSS z-index where upper layers fully occlude lower layers. In optical inspection mode, the vertical Z-axis is separated via translateZ(Layer * 32px * Factor) allowing full structural inspection of all 6 planes.
